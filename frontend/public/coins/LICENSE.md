# Cryptocurrency icon assets

The SVG files in this directory are sourced from the
[`spothq/cryptocurrency-icons`](https://github.com/spothq/cryptocurrency-icons)
project and distributed under the CC0-1.0 license.

This directory contains the full color SVG set so that account assets can use
local icons without relying on an external CDN. `krw.svg` is a project-owned
companion icon for the Korean won balance.
